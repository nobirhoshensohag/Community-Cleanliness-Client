# 🧹 Community Cleanliness — A Sustainable Community Platform

A community-driven platform where users can report cleanliness issues, participate in cleaning challenges, share eco-friendly tips, and contribute to a cleaner environment.

---

- 🌍 **Live Site:** https://community-cleanlinesss.web.app

- 🧠 **Server Repo:** https://github.com/nobirhoshensohag/community-cleanliness-server  

---

## 📘 Project Overview  

**Community Cleanliness** helps users:  
- Report community cleanliness issues  
- contribution in local events  
- Track their own contributions  
- Maintain a cleaner environment together  

---

## 📝 Features  

### 🗑️ Issue Management  
- Add new issues  
- View all issues  
- Edit or delete issues  
- Upload images  
  

### 🗓️ Events
